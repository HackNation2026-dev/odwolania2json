# Materiały UZP i ich pochodzenie

Źródło: https://github.com/Urzad-Zamowien-Publicznych/hacknation-2026

Przypięta rewizja: `f60ca6f9fcd1a624ba145dbc6c658bfb076ece79`. Pozyskanie: 2026-11-21. Zachowano **385 plików** z tej rewizji. Każdy plik sprawdzono względem rozmiaru i identyfikatora Git blob; manifest zespołu dodaje SHA-256. Pobranie przez API GitHub za pośrednictwem narzędzia web; bajty dekodowano z base64 i sprawdzono niezależnie.

## Zawartość

- 60 katalogów przykładów w `dane/` z PDF i referencjami JSON.
- Dokumenty negatywne i instrukcja ich traktowania.
- `oczekiwane-json/`: trzy wzorce i słownik przyczyn odwołania.
- `szablon-aplikacja/`: wejście, wyjście i przykładowe pliki.
- README organizatora, opis i regulamin PDF oraz FAQ v1.0 przekazane przez użytkownika.

[Pełny rejestr plików](rejestr.md). [Rewizja i identyfikatory blobów](uzp-revision.json). [Manifest SHA-256](manifest.json).

README i wzorce mogą zmieniać się na main. Kopia w tym repo jest zamrożona na powyższej rewizji. Aktualizacja wymaga jawnego porównania, zmiany manifestu i wpisu w historii.

## Granice audytu

Kompletność i identyczność bajtów nie oznaczają audytu merytorycznego wszystkich przykładów. Nie uruchomiono ekstrakcji ani oficjalnego ewaluatora. Model i dostawca API nie zostali jeszcze wybrani.
