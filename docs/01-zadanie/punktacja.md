# Punktacja UZP

| Etap / kryterium | Waga lub punkty |
|---|---|
| Preselekcja — F1 na zbiorze testowym | 100% |
| Finał — F1 | 50% |
| Finał — elastyczność i rozbudowa | 50% |

W aktualnym zarchiwizowanym README drugą część finału opisano jako: 1-20 pkt za moc/wielkość modelu, 1-20 pkt za łatwe dodawanie klas i pól, 1-10 pkt za dodatkowe funkcje, np. GUI. Większy model ma otrzymywać mniej punktów w pierwszej składowej. Nie podano jednoznacznego przelicznika wielkości modelu ani szczegółowego algorytmu F1.

Starszy PDF: finał 50% F1 / 30% elastyczność / 20% jakość techniczna. FAQ v1.0 i aktualny README wskazują 50/50. Do planowania przyjmujemy 50/50, zachowując konflikt źródeł do potwierdzenia u mentora.

Źródło szczegółów: [README organizatora](../02-materialy/organizator-uzp/README.md). GUI jest opcjonalne i premiowane. Najpierw spełnij warunki klasyfikacji i ekstrakcji.
